# Pajarraco
Página web de pajarraco:
https://thesculper.github.io/Pajarraco/

Las imágenes del sitio están en `assets/images/`.

El checkout envía el pedido por WhatsApp y coordina el pago por transferencia. El sitio no procesa pagos automáticos. El número de pedidos se configura con `data-whatsapp-phone` en cada página HTML.

El checkout solicita nombre y modalidad de entrega. Los retiros y puntos de encuentro indicados en la tienda son gratuitos; los envíos por courier se cotizan antes de confirmar el pedido. La información de disponibilidad, pagos y cambios se muestra en cada página.
